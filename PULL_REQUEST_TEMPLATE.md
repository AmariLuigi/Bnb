## Merge master into gh-pages

### Update Summary

This update merges the `master` branch into `gh-pages` to enhance the live site with a new centralized data system that enables efficient management of all restaurant and attraction content from a single source. Specifically, the key features include:

- **Dynamic Data System**: All restaurant and attraction content can now be managed centrally from `js/translations.js`.
- **Multi-Language Support**: The new system supports multiple languages, enhancing accessibility for users.
- **QR Code Compatibility**: We have ensured that all existing URLs maintain compatibility for QR codes.

This update is crucial for improving user experience and expanding our service capabilities.
